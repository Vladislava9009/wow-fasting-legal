# Wow Intermittent fasting: legal pages

Privacy Policy, Terms of Use and Support pages for the iOS app
"Wow Intermittent fasting" ([App Store](https://apps.apple.com/app/id6479248621)),
in 8 languages — the same ones the app itself supports.

Source: `make_i18n.py` (texts) -> `i18n.json`; `build.py` generates the HTML.
Published with GitHub Pages.

```bash
python3 make_i18n.py && python3 build.py
```

The app has no servers and no accounts: everything a person enters stays on
their phone. The texts say exactly that, so keep them in step with the app —
if it ever starts sending anything anywhere, these pages must change first.
